Implement Constructor Overloading in Java

📌 Project Overview

This project demonstrates Constructor Overloading in Java. It shows how multiple constructors can be defined in the same class to initialize objects with different sets of information.

🎯 Objective

To understand constructors and constructor overloading by creating a Java class with multiple constructors.

🛠️ Technologies Used

- Programming Language: Java
- IDE/Compiler: Online Java Compiler or any Java IDE

📚 Concepts Covered

- Classes and Objects
- Constructors in Java
- Constructor Overloading
- Parameterized Constructors
- Object Initialization
- Methods and "System.out.println()"

💻 Program Description

The program creates a "Student" class with two variables:

- "name" – stores the student's name.
- "age" – stores the student's age.

It defines three constructors:

1. Default Constructor: Initializes the name to ""Unknown"" and age to "0".
2. Single-Parameter Constructor: Initializes the student's name and sets the age to "0".
3. Two-Parameter Constructor: Initializes both the student's name and age.

A "display()" method prints the details of each student object.

▶️ Sample Output

Name: Unknown
Age: 0

Name: Ravi
Age: 0

Name: Priya
Age: 19

🚀 How to Run the Program

1. Install the Java Development Kit (JDK) or open an online Java compiler.

2. Create a file named "Student.java".

3. Copy the Java program into the file.

4. Compile the program:
   
   javac Student.java

5. Run the program:
   
   java Student

✅ Key Learnings

- A constructor has the same name as its class.
- Constructors do not have a return type.
- Constructor overloading allows objects to be initialized in different ways.
- Java selects the appropriate constructor based on the arguments passed during object creation.
